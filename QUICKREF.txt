WORKFLOW
========

Input: Raw MD simulation data (XVG files)
    ↓
[1] Load equilibrated region (e.g., 50-150 ns)
    ↓
[2] Block averaging (5 or 10 ns blocks)
    ↓ produces independent samples
[3] Descriptive statistics (mean, median, SD, CV, etc.)
    ↓
[4] Bootstrap analysis (10,000 resamples)
    ↓ produces bias-corrected confidence intervals
[5] Autocorrelation & Effective Sample Size
    ↓
[6] Trend analysis (linear regression)
    ↓ detects non-convergence
[7] Convergence testing (compare time windows)
    ↓
[8] Publication-quality figures & tables
    ↓
Output: Comprehensive Excel/CSV/PNG report


QUICK START
===========

1. Install packages:
   pip install -r requirements.txt

2. Verify setup:
   python setup_verify.py

3. Edit config.py (set PROJECT_ROOT, COMPLEXES, etc.)

4. Run analysis:
   python run_analysis.py

5. Check results in analysis_results/

UNDERSTANDING THE STATISTICS
=============================

Descriptive Statistics:
  Mean          Average value
  Median        50th percentile
  SD            Standard deviation (spread)
  SEM           Standard error of mean
  CV            Coefficient of variation (%)
  Min/Max       Range
  IQR           Interquartile range

Bootstrap Results:
  95% CI        Confidence interval (bias-corrected)
  CI Width      Upper - Lower bound
  BCa Method    Bias-corrected and accelerated

Effective Sample Size:
  N Total       Original data points
  N Effective   Independent samples (after accounting for autocorrelation)
  Efficiency    Neff / N_total (%)
  SEM Corrected Standard error adjusted for autocorrelation

Trend Analysis:
  Slope         Rate of change (units/ns)
  R²            Goodness of fit (0-1)
  p-value       Significance (p<0.05 = significant trend)
  Converged     "Yes" if no significant trend


COMMON OUTPUT PATTERNS
======================

Good convergence (what you want):
  ✓ No significant trend (p > 0.05)
  ✓ High Neff (>50% efficiency)
  ✓ Small CV (< 5%)
  ✓ Consistent across time windows

Possible issues:
  ✗ Significant trend (p < 0.05)      → Simulation too short
  ✗ Low Neff (< 20% efficiency)       → Increase block size
  ✗ Large CV (> 10%)                  → High variability
  ✗ Different statistics in windows   → Not converged

Solutions:
  - Increase block size (5 → 10 ns)
  - Extend simulation length
  - Check for equilibration problems
  - Examine time series plots for drifts

Methods section should mention:
  - Block size (5 or 10 ns)
  - Equilibration period (50 ns)
  - Bootstrap method (10,000 samples, BCa)
  - ESS calculation (from integrated ACF)

Example text:
  "All statistics were calculated using block-averaged 
   data (5 ns blocks) from the equilibrated region of the 
   trajectory (50-150 ns). 95% confidence intervals were 
   determined from 10,000 bootstrap resamples using the 
   bias-corrected and accelerated (BCa) method. Effective 
   sample sizes were calculated from the integrated 
   autocorrelation time to account for trajectory 
   correlation."


CUSTOMIZATION
==============

Change block size:
  config.BLOCK_SIZE_NS = 10  # instead of 5

Change equilibration:
  config.EQUILIBRATION_NS = 100  # skip first 100 ns

Change Bootstrap samples:
  config.N_BOOTSTRAP = 50000  # more samples = smoother CI

Change output format:
  config.FIGURE_FORMAT = "pdf"  # or "both"
  config.DPI = 600  # higher quality

Add more descriptors:
  config.XVG_FILES = {
      "rmsd": "rmsd.xvg",
      "rg": "rg.xvg",
      "your_descriptor": "your_file.xvg",  # add here
  }


TROUBLESHOOTING
===============

Issue: "No data loaded"
  → Check XVG file paths in config.py
  → Verify file names are exact (case-sensitive on Linux)

Issue: "Only 3 blocks created"
  → Your trajectory is too short for this block size
  → Edit config.py: reduce BLOCK_SIZE_NS or remove EQUILIBRATION_NS

Issue: "Memory error"
  → Increase block size (5 → 10 ns)
  → Reduce N_BOOTSTRAP (10000 → 5000)

Issue: Poor figure quality
  → Increase DPI: config.DPI = 600
  → Check FIGURE_FORMAT = "pdf" for publication

Issue: "matplotlib not found"
  → pip install matplotlib seaborn

For more help:
  → Check README.txt
  → Run with VERBOSE=2: config.VERBOSE = 2
  → Examine analysis_summary.txt
